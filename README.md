# Australia on Foot

FIT3179 Data Visualisation 2 (draft demo) by Jiajing Xu, Monash University, October 2026.

A Vega-Lite data story about where Australians hike, who participates and what shapes the popularity of national parks.

- `index.html`: the web page
- `specs/`: Vega-Lite JSON specification for each chart and map
- `data/`: datasets (participation, visitor, seasonality and trail figures are **placeholders** in this demo)
